# SEO + AdSense

## SEO Landing Types

### Server
/server/interpark
/server/ticketlink
/server/yes24

### Event
/event/[event-slug]

### University
/university/yonsei
/university/korea
/university/inha

### Guide
/guide/interpark-ticketing
/guide/course-registration

## Metadata
페이지마다 고유:
- title
- description
- canonical
- OG
- JSON-LD where valid

## Thin Content 방지
서버시간 숫자만 있는 페이지 금지.

각 페이지에:
- 서비스 설명
- 관련 이벤트
- 사용 팁
- 정확도 안내
- FAQ
를 제공.

## AdSense Principle
핵심 작업보다 광고가 먼저 나오지 않는다.

Desktop:
Clock / Action
→ Ad
→ Event/Trend
→ Content
→ Ad

Mobile:
Clock
→ Action
→ Event
→ Ad
→ Trend
→ Content

## Focus Mode
광고 표시하지 않음.

## 자동생성 SEO 주의
수천 개의 가치 없는 AI 텍스트 페이지를 대량 생성하지 않는다.
실제 조회되는 host/event 중심으로 페이지를 확장한다.
