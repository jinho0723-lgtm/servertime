# UI / UX Specification

## Design Direction
- Premium
- Precision
- Technical
- Dark
- Minimal
- Trustworthy
- Responsive
- Mobile-first

레퍼런스 감성:
Apple + Linear + TradingView + 스포츠 타이밍 시스템.

## Visual Rules
- 기본 Dark Theme
- 큰 숫자 중심
- 숫자는 tabular-nums
- 광고보다 핵심 시간 UI가 우선
- 과도한 게임 UI 금지
- 과도한 glassmorphism 금지
- 정밀 계측기 느낌 유지

## Focus Mode
광고/커뮤니티/사이드 UI 제거.
정확한 시각과 OPEN 카운트다운만 표시.

## Guest UX
- 회원가입 유도 팝업 금지
- 로그인 요구 금지
- 최초 진입 즉시 기능 사용 가능
- 알람은 필요한 시점에 브라우저 권한만 요청
- 익명 닉네임은 자동생성 후 사용자가 변경 가능

## Mobile

하단 네비게이션 고정.
핵심 숫자는 첫 화면에서 스크롤 없이 보여야 한다.
