# Product Specification

## 한 줄 정의
티켓팅 · 수강신청 · 예약 · 한정판매의 정확한 순간을 잡는 실시간 오픈 플랫폼.

## 핵심 가치

### Precision
- 서버시간
- 밀리초
- 지연시간
- 예상 오차
- 지속 동기화

### Action
- 알람
- Event Mode
- Focus Mode
- Mini Clock
- 카운트다운

### Discovery
- 오늘의 오픈
- 이번주 오픈
- 인기 서버
- 급상승 이벤트

### Engagement
- 티켓팅 연습
- 이벤트별 실시간 대기실
- 성공 인증

## 핵심 사용자
- 콘서트/뮤지컬/팬미팅 티켓팅 사용자
- 대학 수강신청 사용자
- 스포츠 예매 사용자
- 예약 오픈 사용자
- 팝업/한정판 구매 사용자

## 운영 원칙
관리자가 이벤트를 직접 입력하지 않는다.

이벤트는 자동수집 파이프라인에서 생성되며,
관리자 개입은 수집 오류/중복/분류 실패 등 예외 처리에만 사용한다.

## 계정 정책
완전 비회원제.

로그인/회원가입 없이:
- 서버시간 조회
- 알람 설정
- 즐겨찾기
- 최근 조회
- 티켓팅 연습
- 연습 기록
- 이벤트 대기실
- 익명 채팅
- 성공 인증
을 사용할 수 있어야 한다.

개인 기록은 브라우저 저장소 기반으로 유지한다.
