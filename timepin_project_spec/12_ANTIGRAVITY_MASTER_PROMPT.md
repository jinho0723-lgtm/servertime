# Antigravity Master Prompt

Build TIMEPIN as a production-ready responsive web product using the included specification files and design_reference.png.

Core product identity:
A premium precision timing platform for ticketing, course registration, reservations and limited releases.

Do not build it as a generic SaaS dashboard.

## Critical
- Guest-only product.
- No signup/login/auth screens.
- Zero routine administrator content entry.
- Events are automatically collected and normalized.
- Precision timing is the primary product feature.
- Milliseconds must be rendered with tabular numbers.
- Show estimated accuracy honestly.
- Mobile UX must be first-class.

## Primary screens
1. Home
2. Server time
3. Event
4. Focus mode
5. Practice center

8. Mobile variants
